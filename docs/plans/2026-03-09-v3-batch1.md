# Pomodoro Timer v3 — Batch 1 Implementation Plan

> **For Claude:** Web is single-file inline in `index.html`. macOS is SwiftUI project under `PomodoroTimer/`. Execute tasks sequentially by priority. Each task = one commit.

**Scope:** 5 features — F-05, F-03, F-01, F-08, F-04
**Estimated effort:** 2-3 hours total
**Prerequisite:** v2 fully functional on both platforms

---

### Task 1: F-05 Tab Title Timer (Priority 1, XS)

**Files:**
- Modify: `index.html`
- Modify: `PomodoroTimer/PomodoroTimer/TimerManager.swift`
- Modify or create: `PomodoroTimer/PomodoroTimer/PomodoroTimerApp.swift`

**Step 1: Web — Update document.title in updateDisplay()**

In `updateDisplay()`, after setting `timerDisplay.textContent`, add title sync logic:
- `state === 'running' || state === 'paused'` → `document.title = MM:SS + ' - Pomodoro'`

**Step 2: Web — Update title in showAlert() and dismissAlert()**

- `showAlert()` → `document.title = '时间到！'`
- `dismissAlert()` → `document.title = 'Pomodoro Timer'`

**Step 3: macOS — Add Dock badge in TimerManager**

In `TimerManager`, add a `remaining` `didSet` observer (or Combine publisher in `PomodoroTimerApp`) to update `NSApplication.shared.dockTile.badgeLabel`:
- `state == .running || state == .paused` → display minutes string
- `state == .alert` → `"!"`
- `state == .idle` → `""` (clear)

**Verify:**
- Web: Start timer, switch tab, tab title shows countdown. Alert shows "时间到！". Dismiss restores "Pomodoro Timer"
- macOS: Start timer, check Dock badge. Alert shows "!". Dismiss clears badge

### Task 2: F-03 Progress Indicator (Priority 2, XS)

**Files:**
- Modify: `index.html`
- Modify: `PomodoroTimer/PomodoroTimer/ContentView.swift`

**Step 1: Web — Add progress bar HTML**

Inside `<div id="app">`, between `#timerDisplay` and `#actionBtn`, add a progress track div with a progress fill child div.

**Step 2: Web — Add progress bar CSS**

- `.progress-track`: width 320px, height 2px, background `#E0E0E0`, border-radius 1px, opacity 0 by default
- `.progress-track.visible`: opacity 1
- `.progress-fill`: height 100%, background `#000000`, border-radius 1px, width 0%

**Step 3: Web — Update progress in updateDisplay()**

When `state === 'running' || state === 'paused'`:
- Show track (add `visible` class)
- Set fill width: `((DURATION - remaining) / DURATION) * 100 + '%'`

Otherwise: hide track, reset fill to 0%.

**Step 4: macOS — Add progress bar in ContentView**

Below `Text(timeString)`, add `GeometryReader` with `ZStack`:
- Background: `RoundedRectangle` fill `#E0E0E0`, height 2
- Fill: `RoundedRectangle` fill `.black`, width = `geo.size.width * progress`, height 2
- `.opacity()` bound to running/paused state
- Progress formula: `(defaultDuration - remaining) / defaultDuration`

**Verify:**
- Start timer → bar appears, fills left-to-right
- Pause → bar stays at current position
- Dismiss → bar disappears
- Idle → no bar

### Task 3: F-01 Breathing Animation (Priority 3, XS)

**Files:**
- Modify: `index.html`
- Modify: `PomodoroTimer/PomodoroTimer/ContentView.swift`

**Step 1: Web — Add CSS keyframes**

Define `@keyframes breathing`: opacity 1 → 0.88 → 1, 4s cycle, ease-in-out.
Add `.breathing` class applying this animation.

**Step 2: Web — Toggle class on state change**

- State becomes `running` → `timerDisplay.classList.add('breathing')`
- State becomes `paused`/`idle`/`alert` → `timerDisplay.classList.remove('breathing')`

**Step 3: macOS — Add breathing opacity in ContentView**

Add `@State private var breathingOpacity: Double = 1.0`.
On `Text(timeString)`:
- `.opacity(timerManager.state == .running ? breathingOpacity : 1.0)`
- `.onChange(of: timerManager.state)`: if `.running` → animate to 0.88 with repeatForever; else → animate back to 1.0

**Verify:**
- Start → digits pulse opacity
- Pause → pulsing stops, fully opaque
- Resume → pulsing resumes

### Task 4: F-08 Session Counter (Priority 4, S)

**Files:**
- Modify: `index.html`
- Create: `PomodoroTimer/PomodoroTimer/SessionCounter.swift`
- Modify: `PomodoroTimer/PomodoroTimer/ContentView.swift`
- Modify: `PomodoroTimer/PomodoroTimer/PomodoroTimerApp.swift`

**Step 1: Web — Add counter storage logic**

- `loadSessionCount()`: read localStorage JSON `{date, count}`, validate date matches today, return count or 0
- `saveSessionCount(count)`: write JSON with today's date
- Initialize `sessionCount` at page load
- Constant `SESSION_GOAL = 4`

**Step 2: Web — Add counter HTML and CSS**

After `#actionBtn`, add container div for dots.
- `.session-dots`: flex, gap 8px, margin-top 40px
- `.session-dot`: width/height 8px, border-radius 50%
- `.session-dot.filled`: background `#CCCCCC`
- `.session-dot.empty`: transparent bg, 1px solid `#E8E8E8`

**Step 3: Web — Render dots function**

`renderSessionDots()`:
- If count === 0: clear container
- total = max(count, SESSION_GOAL)
- Generate dots: filled for completed, empty for remaining
- Call at page load and after incrementing in `dismissAlert()`

**Step 4: Web — Increment in dismissAlert()**

In `dismissAlert()`, before state reset: increment count, save, render dots.

**Step 5: macOS — Create SessionCounter.swift**

`SessionCounter: ObservableObject`:
- `@Published var count: Int`
- `let goal = 4`
- `init()` → load from UserDefaults, validate date
- `increment()` → count += 1, save
- Private: `load()`, `save()`, `dateString()` using DateFormatter

**Step 6: macOS — Add dots UI in ContentView**

Below action button, add HStack with Circle views:
- Show only when `count > 0`
- Filled circles for completed, stroked empty circles for remaining
- Frame: 8x8 per dot, 8px spacing, 40px top padding

Call `sessionCounter.increment()` in overlay dismiss callback.

**Verify:**
- Complete a pomodoro → dot appears
- Refresh/restart → dot persists
- Date change → dots reset
- Exceed goal → extra filled dots, no empty ones

### Task 5: F-04 Alert Overlay Enhancement (Priority 5, S)

**Files:**
- Modify: `index.html`
- Modify: `PomodoroTimer/PomodoroTimer/AlertOverlayManager.swift`

**Step 1: Web — Add overlay animation CSS**

- `@keyframes alertBreathe`: background-color `#E74C3C` → `#C0392B`, 3s ease-in-out infinite
- `@keyframes textPulse`: scale 1 → 1.02, 2s ease-in-out infinite
- `.overlay:not(.hidden):not(.dismissing)`: apply alertBreathe
- `.overlay:not(.hidden) .overlay-title`: apply textPulse
- `.overlay.dismissing`: transform scale(0.95), opacity 0, transition 300ms ease-out

**Step 2: Web — Refactor dismissAlert() to two-phase**

1. Add `dismissing` class to overlay
2. Listen for `transitionend` (once)
3. On transition end: add `hidden`, remove `dismissing`, execute reset logic (state, display, title, session counter)

**Step 3: macOS — Add overlay animations in AlertOverlayView**

- Background: `@State var alertBgColor` toggling between two reds with `.animation(.easeInOut(duration: 3).repeatForever(autoreverses: true))`
- Title: `.scaleEffect(textScale)` toggling 1.0 ↔ 1.02 with similar animation

**Step 4: macOS — Add dismiss animation in AlertOverlayManager**

- `dismissOverlay()`: set `dismissing = true` → `withAnimation(.easeOut(duration: 0.3))` opacity → 0 → after delay close windows
- Ensure all `overlayWindows` animate simultaneously

**Verify:**
- Alert → red background pulses between two reds
- "时间到！" text gently scales
- Press key → overlay shrinks + fades ~300ms
- macOS: all screens in sync
